# 캘린더 세트 (Calendar Sets)

여러 캘린더 조합을 이름 붙여 저장하고, 피커로 한 번에 전환한다. (Fantastical의 "Calendar Sets"와 유사)

## 배경 / 전제
- **무료 기본 기능이다.** 2026-06-26(커밋 `565956d`)에 IAP(`PremiumStore`/`PaywallView`/`Petals.storekit`)를 제거하고 **"한 번 사면 전 기능 해제"인 유료 앱**으로 전환함. 따라서 캘린더 세트는 StoreKit 게이팅 없이 전 사용자에게 무료로 제공한다. 이 기능 때문에 StoreKit을 되살리지 않는다.
- 이메일 원안은 "additive 체크박스(여러 세트 동시 on)"였으나, 논의 끝에 **단일 활성 세트(피커로 하나만 선택)** 모델로 확정. 더 단순하고 기존 개별 체크박스 UX와 충돌하지 않는다.

## 문제 (JTBD)
캘린더가 많은 사용자는 상황에 따라 보고 싶은 캘린더 묶음이 다르다(업무 / 가족 / 특정 프로젝트 등). 지금은 매번 개별 캘린더를 하나씩 켜고 꺼야 한다. → **"지금 이 맥락에서 볼 캘린더 묶음"을 한 번에 전환**하고 싶다.

## 범위
**목표**
- 캘린더 조합을 이름 붙여 저장(세트)하고, 피커로 즉시 전환.
- "기본" 세트로 기존 선택을 무손실 이관.
- 세트 생성 / 이름변경 / 삭제 / 순서변경.

**비목표 (YAGNI — 필요해지면 별도로)**
- 세트 동시 다중 활성(additive)
- 세트 동기화(CloudKit) — 로컬 저장으로 확정
- 세트 복제, 세트별 색상/아이콘, 시간·위치 기반 자동 전환
- "찾을 수 없는 캘린더" 관리 UI (일단 조용히 무시)

## 핵심 모델: 단일 활성 세트
- **세트 = 캘린더 조합의 명명된 스냅샷.** `{ id, name, calendarIDs }`.
- **한 번에 하나만 활성**(피커). 렌더링되는 선택 = **활성 세트의 캘린더들**.
- **"기본" 세트**: 삭제 불가(이름 변경은 허용). 앱 업데이트 시 기존 선택이 자동으로 "기본"이 됨 → 초기 활성 세트.
- **개별 캘린더 체크박스 = 활성 세트를 실시간 편집(WYSIWYG).** 별도 저장 버튼 없음. "업무"를 보다가 캘린더 하나 끄면 "업무" 세트 정의가 바뀐다.
- **`selectedCalendarIDs`는 활성 세트의 미러.** 렌더 파이프라인은 지금처럼 `selectedCalendarIDs`만 읽는다(수술 최소화). 활성 세트가 바뀌거나 멤버가 편집되면 이 값을 다시 채운다.

## 데이터 & 저장 (로컬)
`selectedCalendarIDs`와 동일하게 **UserDefaults**에 저장(SwiftData/CloudKit 아님).
- `"calendarSets"` → JSON 인코딩된 `[CalendarSet]` (`Codable`). 각 원소: `id: String`, `name: String`, `calendarIDs: [String]`.
- `"activeCalendarSetID"` → String.
- **기본 세트의 `id`는 예약 상수**(예: `"default"`)로 고정 → "삭제 불가" 판정에 사용. 이름은 `id`와 분리 저장하므로 자유롭게 변경 가능.
- 세트는 **`calendarIdentifier`만 저장**한다. 캘린더 **이름·색은 항상 EventKit에서 실시간 조회**(저장본 캐시 없음).

## 마이그레이션 (기존 사용자 무손실)
새 버전 첫 실행 시 `"calendarSets"`가 없으면:
1. 레거시 `"selectedCalendarIDs"`를 읽어 `기본` 세트 생성 = `{ id:"default", name:"기본", calendarIDs: <레거시> }`.
2. `activeCalendarSetID = "default"`.
3. 신규 사용자(레거시 선택 없음)는 빈 "기본" 세트로 시작(현재의 "첫 실행 시 아무것도 선택 안 됨"과 동일).

## 견고성 — 캘린더 삭제/이름변경
- **이름 변경** → 문제 없음. `calendarIdentifier`는 불변이라 세트가 그대로 가리키고, 체크박스엔 새 이름이 자동 표시.
- **삭제/계정 오프라인** → 그 ID는 렌더 시 **무시**(이벤트 0, 크래시 없음). **저장된 ID는 유지** → 캘린더가 돌아오면 세트가 자기치유. **자동 prune 없음**; 사용자가 그 세트를 직접 편집할 때만 실제로 빠진다.
- 세트의 모든 캘린더가 사라져도 유효(이벤트 없이 표시). 크래시 없음.

## UI / 동작 — 기존 `CalendarFilterView` 확장
상단에 세트 피커를 얹고, 그 아래는 지금의 개별 캘린더 체크박스 목록 유지.
```
세트: [ 기본            ▾ ]
        ● 기본
          업무
          가족
        ──────────────────
        + 현재 선택을 새 세트로 저장…
        세트 관리…
── CALENDARS ──
 ☑ 회의   (iCloud)
 ☑ 개인
 ☐ 생일
```
- **전환**: 피커에서 세트 선택 → `selectedCalendarIDs` = 그 세트, 체크박스 갱신, 캘린더 다시 그림.
- **멤버 편집**: 체크박스 토글 → 활성 세트 정의를 즉시 수정·저장.
- **추가(주 경로)**: **"+ 현재 선택을 새 세트로 저장…"** → 이름 입력 → 현재 체크 상태를 **복제한 새 세트를 만들고 그 세트로 전환**. 이후 체크박스 편집은 새 세트에 반영(활성 세트 실시간 편집 규칙에 따름) → **"먼저 새 세트로 저장 → 그다음 다듬기"** 순서 권장(안 그러면 다듬는 동안 이전 활성 세트가 바뀜).
- **세트 관리… 시트**: 이름 인라인 편집, 삭제(🗑, 기본은 비활성), 드래그(⠿) 순서변경, "+ 빈 세트 추가".

## 구현 (변경 지점)
1. **`Models/CalendarSet.swift`** (신규): `struct CalendarSet: Codable, Identifiable { id, name, calendarIDs }`, 기본 세트 `id` 상수.
2. **`EventKit/EventManager.swift`**:
   - `calendarSets: [CalendarSet]`, `activeCalendarSetID: String` (UserDefaults 로드/저장, 기존 `selectedCalendarIDs` didSet 패턴 참고 — `EventManager.swift:16-21`, `:46-53`).
   - 마이그레이션 로직(첫 실행 시 레거시 → 기본 세트).
   - `selectedCalendarIDs`를 활성 세트 미러로 유지: 활성 세트 변경/멤버 편집 시 재계산 + `loadedYear` 캐시 무효화(기존 didSet 동작 유지).
   - CRUD 메서드: `select(setID:)`, `saveCurrentAsNewSet(name:)`, `rename(setID:to:)`, `delete(setID:)`(기본 거부; 활성 세트 삭제 시 "기본"으로 폴백), `move(...)`.
3. **`Views/CalendarFilterView.swift`**: 상단 세트 피커 + "새 세트로 저장" + "세트 관리…" 진입 추가. 개별 체크박스 `binding(for:)`은 활성 세트 편집으로 연결(현재 `selectedCalendarIDs` 직접 편집 → 활성 세트 경유).
4. **`Views/CalendarSetManageView.swift`** (신규): 관리 시트.
5. **로컬라이징**: 신규 문자열("기본", "세트", "새 세트로 저장…", "세트 관리", "이름", "삭제" 등) 기존 방식대로 번역 추가.

## 건드리지 않는 것
- 이벤트 렌더/레이아웃 파이프라인 — `selectedCalendarIDs`만 계속 읽으므로 무변경.
- StoreKit/IAP — 되살리지 않음.
- 비전보드/캔버스, 테마, 폰트 설정.

## 검증 (통과 기준)
- 빌드 성공.
- 기존 선택이 있는 사용자로 업데이트 → "기본" 세트에 그대로 담기고 화면 동일(무손실).
- 캘린더 몇 개 켜고 "새 세트로 저장" → 이름 붙인 세트 생성, 피커로 전환 시 해당 캘린더만 표시.
- "업무" 활성 중 캘린더 토글 → "업무" 세트가 즉시 바뀌고, 다른 세트 갔다 오면 유지됨.
- "기본"은 삭제 버튼 비활성; 다른 세트 삭제 시 활성 세트였다면 "기본"으로 폴백.
- Calendar.app에서 세트 내 캘린더 **이름 변경** → 세트 유지, 새 이름 표시.
- Calendar.app에서 세트 내 캘린더 **삭제** → 크래시 없이 조용히 빠지고, 되돌리면(계정 재추가) 복구.
- 앱 재시작 후 세트 목록·활성 세트 유지.
