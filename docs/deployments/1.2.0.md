| 승인 근거 | 지원 언어를 Peek와 같게 추가하고 전부 번역한 뒤 App Store 배포 요청 |

## 변경 사항

- Peek와 동일한 7개 언어: en, ko, de, es, fr, ja, pt-BR.
- 앱 문자열 256개, Info.plist 문자열 4개 전체 번역.
- 캘린더 전체 접근 권한 설명 추가 및 번역.
- 긴 번역을 위한 설정 창과 기간 레이블 공간 조정.
- 7개 언어 App Store 메타데이터 업로드 후 원격 값 일치 검증.
- 기존 main 작업의 계획판, 메모, 검색, 내보내기 개선 포함.

## 릴리즈 노트

정확한 언어별 원문은 이 태그의 `fastlane/metadata/*/release_notes.txt`에 보존한다.

| 언어 | 내용 |
| --- | --- |
| 한국어 | 독일어, 스페인어, 프랑스어, 일본어, 포르투갈어(브라질)를 지원합니다. 계획판, 날짜별 메모, 일정 검색을 추가했습니다. 캘린더를 PDF·PNG로 내보내거나 인쇄할 수 있습니다. iCloud 동기화와 캘린더 조작을 개선했습니다. |
| English | Added German, Spanish, French, Japanese, and Brazilian Portuguese. Added planning boards, dated notes, and event search. Export calendars as PDF or PNG, or print them. Improved iCloud sync and calendar controls. |

## 검증

- Release macOS 로컬 빌드 성공 (서명 제외).
- 7개 언어 전체 키·번역 상태·형식 지정자 검사 통과.
- 컴파일러 추출 UI 키 180개 전부 카탈로그에 포함.
- 빌드된 앱의 7개 lproj와 캘린더 전체 접근 권한 키 확인.
- 독일어 실제 실행: 연간 캘린더와 설정 화면 번역·배치 확인.
- 시간대 3개 × 514 회귀 검증 통과.
- 계획판 복제·삭제·마이그레이션·메모 보존 및 PDF·PNG·인쇄 검사 통과.
- CloudKit 실제 기기 간 동기화는 이 번역 변경에서 재검증하지 않음.

클라우드 빌드·심사 제출 결과는 태그 생성 후 별도 기록한다.
